Revisión de palabras marcadas · Puno Quechua

Instrucciones / Instructions

Escucha el audio. Las palabras resaltadas son las que el sistema considera dudosas. Para cada una, elige la opción que mejor corresponde a lo que se oye: una de las alternativas, — (sin palabra) si esa palabra no se dice, Otra para escribir otra forma, o No sé si no puedes decidir. "No sé" es una respuesta válida y útil.

Ortografía de Puno: q (uvular, más atrás que k), h tras consonante = aspirada (kh, ph, qh, chh, th), apóstrofo = eyectiva (k', p', q', ch', t'), ll, ñ, sh; solo vocales a, i, u en palabras quechuas. Las palabras prestadas del castellano se escriben como se oyen.

La palabra que suena se subraya en azul; haz clic en cualquier palabra para saltar a ese momento, o usa ▶ escuchar para oír solo esa parte.

Atajos: espacio reproducir/pausar · 1–9 elegir opción en la primera palabra pendiente · 0 No sé · n siguiente · p anterior.
